Privacy policy

The tool requests the Google Drive drive.file permission. It uses it to write, read and verify backup files and repository metadata it creates or uses. It does not request access to the rest of the owner’s Google Drive.

Server data and filenames are encrypted with Restic before upload. The owner keeps the recovery key and Google OAuth credential in private storage. Backup files stay in the owner’s Google Drive account. The tool does not sell Google user data, use it for advertising, or share it with other people. Its use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

The owner controls backup retention and can delete backups in Drive. They can revoke access in Google Account connections. Revoking access stops future operations; it does not remove existing files.

Contact the owner using the support address displayed in Google’s consent screen. This static information site is hosted by GitHub Pages. See GitHub’s privacy statement for hosting data practices.
